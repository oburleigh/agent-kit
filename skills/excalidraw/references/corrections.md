# Corrections log

When a user rates a diagram and gives feedback, act on it immediately: update the relevant reference file (`design-principles.md`, `diagram-patterns.md`, `theme.json`, or the layout script) in the same session. Then log the correction below the divider so the change history is visible.

Entry format:

## YYYY-MM-DD: short description
**Rating:** N/10
**What went wrong:** concrete observation
**What was expected:** concrete expectation
**Pattern:** generalisable rule
**Applied to:** which file was updated
